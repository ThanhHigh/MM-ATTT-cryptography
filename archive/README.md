
Kiểm tra tính nguyên tố bằng AKS (dành cho học tập)
===============================================

Tệp trong thư mục
- `aks.py`: hiện thực thuật toán AKS và hàm `is_prime_aks(n, verbose=False)`.

Cách dùng
---------
Mở cửa sổ lệnh vào thư mục `Kiem_tra_SNT_AKS\src` rồi chạy:

```
python aks.py 101 --verbose
```
